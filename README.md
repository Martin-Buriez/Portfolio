# Portfolio — Martin Buriez

Portfolio personnel, Next.js (App Router) + TypeScript + Tailwind CSS.

## Développement

```bash
yarn dev
```

Ouvre [http://localhost:3000](http://localhost:3000).

## Structure

- `app/` — pages : accueil (`/`), CV (`/cv`), projets (`/projects`)
- `components/` — composants réutilisables (header, footer, cards, carrousel)
- `lib/` — datas
- `public/projects/` — screen des projets

## Build

```bash
yarn build
yarn start
```
